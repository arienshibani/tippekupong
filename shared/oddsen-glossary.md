# Oddsen glossary

Terms as they appear on Norsk Tipping's Oddsen, with English meanings. Verify against the site; labels may change.

| Oddsen term | Meaning |
|---|---|
| **H / U / B** | Hjemmeseier / Uavgjort / Borteseier: home win / draw / away win (1X2). |
| **Over / Under** | Total goals (or points) above or below a line, e.g. Over 2.5. |
| **Handikap** | Handicap market; one side starts with a goal advantage. |
| **Begge lag scorer** | Both teams to score (Yes/No). |
| **Kombinasjon / kombispill** | Accumulator: several selections on one coupon, odds multiplied. |
| **Enkeltspill** | Single bet. |
| **Live** | In-play betting while the event is running. |
| **Kupong** | Bet slip / coupon. |
| **Innsats** | Stake. |
| **Gevinst** | Winnings. |
| **Tapsgrense** | Loss limit set on your Norsk Tipping account. |
| **Spillepause** | Self-imposed break from playing. |

## Tipping (pool games)

Terms for the pool coupons (Tipping). Verify against the site.

| Term | Meaning |
|---|---|
| **Tipping / tippekupong** | Pool game: predict 1X2 for a fixed list of matches; winners share a pool. |
| **Rekke** | One row: a single full set of picks, one outcome per match. Priced per row. |
| **Gardering** | Marking more than one outcome in a match, which multiplies the number of rows. |
| **Halvgardering** | Half cover: two outcomes in a match (1X, X2 or 12). Doubles the rows. |
| **Helgardering** | Full cover: all three outcomes (1X2) in a match. Triples the rows. |
| **Spiker** | A single mark you are confident in (also "spikre": to lock in). |
| **Folkets fordeling** | The public split: the share of players tipping each outcome per match. |
| **Premie** | The prize per winner in a tier. The prize money is shares of the round's turnover (see `tipping-payout-rules.md`). |
| **Spillefrist** | The deadline for buying rows in a round. |
| **Omsetning** | Turnover: the total staked in the round; the prizes are shares of it. |
| **Premieprognose** | The prize forecast Norsk Tipping shows while a round is running (winners and prize per tier). |
| **Folket / Ekspert** | The "Tips" options on the coupon: fill in what the public picks most, or what Norsk Tipping's experts pick. The same percentages are shown per match. |
| **Enkeltrekker / System** | Playing single rows, or a system with several marks in some matches (gardering). |
| **12 / 11 / 10 rette** | The three prize tiers: that many matches correct. |

## Notes on Oddsen as a bookmaker

- Norsk Tipping is the state-owned operator and the only licensed sports betting provider in Norway.
- Because it isn't competing on price, margins on some markets can be higher than at sharp international books. Value is still possible, especially where Oddsen's line lags the wider market.
- Rules for void bets, postponed matches and extra time are in Norsk Tipping's terms. Skills should link to them rather than restate them.
